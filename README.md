# 🎓 I-Learning Himalkom IPB

Platform edukasi berbasis web terpusat yang dirancang untuk meruntuhkan batasan eksklusivitas belajar di lingkungan Departemen Ilmu Komputer IPB University. I-Learning mengintegrasikan *roadmap* pembelajaran dari 7 komunitas IT Himalkom agar dapat diakses secara inklusif oleh seluruh mahasiswa.

## 🚀 Fitur Utama

### 👨‍🎓 Sisi Pengguna 
* **Autentikasi Terpusat:** *Login* dan Registrasi aman menggunakan integrasi Email domain IPB.
* **Eksplorasi Inklusif:** Akses terbuka ke profil dan kurikulum dari 7 komunitas IT (CSI, IWDC, AgriUX, Daming, Gary, MAD, dan CP).
* **Pemilihan Spesialisasi:** Kebebasan memilih *learning path* secara mandiri sesuai dengan minat karier.
* **Interactive Skill Tree:** Visualisasi kurikulum berbasis *node* dengan indikator status belajar (*Done* / *Being studied*).
* **Real-Time Progress Tracking:** Pelacakan progres belajar yang tersinkronisasi otomatis tanpa perlu memuat ulang halaman.

### 👨‍💻 Sisi Admin Panel
* **Analytics Dashboard:** Visualisasi data statistik "Total Views", "Mahasiswa per Komunitas", dan metrik *Completion Rate*.
* **Manajemen Kurikulum Dinamis (CRUD):** Tambah, edit, dan hapus materi, *embed* video, serta referensi pendukung secara langsung melalui antarmuka web.
